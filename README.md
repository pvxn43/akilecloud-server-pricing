**流量方向按产品线分开看。** 轻量云服务器的官方购买须知写的是“按照出向单向计费”，上传不计费。大带宽套餐页多数标注 In+Out（进出都算）。同是 AkileCloud 的产品，计费口径不一样，下单前在套餐页确认。
